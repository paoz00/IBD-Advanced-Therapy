# IBD Advanced Therapy 選択支援 Ver.3.13.0

潰瘍性大腸炎（UC）・クローン病（CD）の高度治療候補を、患者背景・既治療・安全性・投与希望から比較する医療従事者向けWebアプリです。診断、処方、添付文書の確認を代替しません。

## Ver.3.13.0の変更点

- Head-to-Head試験を主要臨床試験へ正式に統合
- UC：VARSITY（VDZ対ADA）を直接比較グラフで表示
- CD：SEAVUE（UST対ADA）を直接比較グラフで表示
- CD：GALAXI 2/3（GUS対UST）を直接比較グラフで表示
- 試験タブと詳細画面へ「H2H／HEAD-TO-HEAD 直接比較試験」表示を追加
- Head-to-Head結果の推奨配点と「直接比較データ」タグを維持
- iPhoneなどの縦表示で入力しやすいよう、基本情報を「疾患→年齢区分→性別→活動性」の順へ変更
- 推奨候補カードへ折りたたみ式の「投与スケジュールを見る」を追加し、導入期から維持期までをタイムラインで図示
- 投与スケジュールはPCでは横型、iPhoneなどの狭い画面では縦型で表示

- 男性では妊娠希望・妊娠中・授乳中の入力を完全に非表示
- 女性でも閉経後は上記入力を非表示にし、保持していた値も解除
- 必須項目入力後、「推奨結果を見る」を押した時だけ採点・表示
- 結果表示後に入力を変えた場合は古い結果を非表示
- 同点は競技順位（1位、1位、3位）で表示
- 最高点との差、加点・減点理由を表示
- 臨床試験をVer.3.1.0に近い一覧カード形式へ変更
- UC/CDごとの適応候補、既治療歴、CDST、肛門病変、内服アドヒアランス、皮下注・内服・点滴希望を評価
- 「入力内容を修正」「最初からやり直す」を追加
- PC・スマートフォン対応
- 疾患の初期値を未選択にし、UC/CD選択を必須化
- 女性のライフステージに「どれにも当てはまらない」を追加
- 疾患別に既使用Advanced Therapyを複数選択し、推奨候補から除外
- 主要臨床試験の結果を実薬群・対照群の横棒グラフで表示
- 一次資料へのリンクと、試験間の単純比較を避ける注意書きを追加
- UTF-8指定を強化し、結果表示の文字化けを修正
- ミリキズマブをCD候補へ追加し、VIVID-1・VIVID-2の主要結果グラフを収録
- ゴリムマブをUC候補・既使用ATへ追加し、PURSUIT-SC・PURSUIT-Jを収録
- グセルクマブのASTRO試験（皮下注導入・維持）の主要結果を収録
- 3剤以上の同点で順位が `undefined` になる不具合と表示の重なりを修正
- 臨床試験カードのクリック領域、ダイアログ互換性、GitHub Pagesのキャッシュ更新を修正
- 高度治療歴を疾患別ATの複数選択へ一本化し、既治療分類を自動判定
- 悪性腫瘍既往・感染リスク・65歳以上の評価を薬剤別に細分化
- 悪性腫瘍既往ではVDZ +10、UST +8、IL-23p19 +4、JAK -12として相対評価
- 1薬剤に複数の臨床試験を登録できる試験別タブ表示へ変更
- IFXのACT・ACCENT、ADAのULTRA・CLASSIC・CHARM、GUSのQUASAR・ASTRO・GALAXIを収録
- VEDのGEMINI 1・2を収録
- RISのINSPIRE・COMMAND・ADVANCE・MOTIVATE・FORTIFYを収録
- ETRのELEVATE UC 12・52を収録
- TOFのOCTAVE Induction 1・2／Sustainを収録
- UPAのU-ACHIEVE・U-ACCOMPLISH・U-EXCEL・U-EXCEED・U-ENDUREを収録
- 未入力項目の赤枠表示、トースト通知、該当項目への自動スクロールを追加
- 臨床試験タブの初期表示を選択中のUC/CDと連動
- 推奨薬カードへ評価タグと主要な配点理由を表示
- 年齢の直接入力を廃止し、「15～64歳」「65～74歳」「75歳以上」の選択式へ変更
- 75歳以上では感染症・心血管・血栓塞栓症リスクをより慎重に評価
- 心血管リスクの独立入力を追加し、75歳以上のJAK阻害薬にはより強い慎重評価を適用
- 投与経路を導入期と維持期に分け、複数経路を持つ薬剤を正しく評価
- VDZの「点滴導入→点滴または皮下注維持」、GUSの「点滴または皮下注導入→皮下注維持」を反映
- 二次無効、増量・間隔短縮、追加・再導入の希望を独立して入力
- IFX・ADA・UST・GUS・MIRI・RISの治療最適化余地を疾患別・条件付きで加点
- 通院増加、点滴時間、自己注射、注射回数増加、服薬管理の許容範囲を入力可能
- 治療背景セクションは通常「02」、女性のライフステージ表示時のみ自動的に「03」へ変更
- 導入療法の投与経路へ「こだわらない」を追加し、具体的な経路選択とは排他的に制御
- 点滴・皮下注・こだわらないを選択した場合だけ維持療法の希望経路を表示し、内服のみなら維持期も内服へ自動設定
- 主要臨床試験カードを作用機序別（抗TNFα抗体、抗インテグリン、IL-12/23、IL-23、JAK、S1P）に色分けし凡例を追加
- 選択した疾患に連動し、UCではUC関連試験のみ、CDではCD関連試験のみをカードとダイアログに表示
- Head-to-Head試験を疾患・対象集団に応じて採点へ反映
  - UC：VARSITYでADAに対する優越性が示されたVDZを+4
  - CD：GALAXI 2/3でUSTに対する複数評価項目の優越性が示されたGUSを+4
  - CD：SEAVUEは生物学的製剤未使用例でUSTとADAに有意差がなかったため、両剤とも0点の根拠表示のみ
  - CD：VIVID-1の既治療失敗例におけるWeek 52組織学的反応を、該当時のみMIRIへ+2の補助加点
- 主要臨床試験へVARSITYとSEAVUEの直接比較グラフを追加
- 同一作用機序内の投与負担を、他の臨床要素より弱い1点差で補助評価
  - S1P受容体調節薬：導入時にスターターパックで7日間の漸増が必要なオザニモドを-1
  - JAK阻害薬：維持療法でも1日2回内服が必要なトファシチニブを-1
  - 1日1回内服のエトラシモド、フィルゴチニブ、ウパダシチニブは基準点を維持
- 導入期に内服を選ばない場合は維持期の選択肢から内服を除外
- 導入期が皮下注のみの場合は維持期を皮下注へ自動設定し、不要な維持経路選択欄を非表示
- 許容できる投与負担を選択中の経路へ連動し、内服・皮下注・点滴に必要な項目だけを表示
- 経路変更によって非表示になった投与負担のチェックは自動解除
- 使用済みATがない場合は「過去に二次無効・効果減弱があった」を非表示にし、AT選択時だけ表示
- UPAの維持療法における15mgから30mgへの増量選択肢を治療最適化として条件付き加点
- 主要臨床試験の実薬グラフ、選択中タブ、ダイアログ上端を作用機序グループの色へ連動
- 投与経路・治療最適化は通常「03」、CD固有情報が表示される場合のみ自動的に「04」へ変更
- 投与経路の初期未選択時は「許容できる投与負担」の見出しを含むブロック全体を非表示
- 女性かつ75歳以上では「閉経後」を自動選択し、妊娠・授乳関連項目を解除して非表示
- 治療背景冒頭の重複していた「高度治療歴」案内文を削除
- 患者背景へ「AZA／6-MP内服中」を追加し、IFXへ+4点の条件付き加点
- IFXの臨床試験へSONIC（CD）とUC-SUCCESS（UC）のAZA併用比較グラフを追加
- 導入療法で「こだわらない」を選択した場合は維持療法も自動的に「こだわらない」とし、維持経路欄を非表示
- 治療最適化の選択肢を導入経路に連動し、内服・皮下注・点滴で利用可能な項目だけを表示
- 使用済みATごとに一次無効、二次無効、有害事象中止、寛解後中止、その他を記録
- 使用済みATを選択した場合は使用後の経過を必須入力とし、未選択時は赤枠と通知で案内
- 一次無効・有害事象中止を同一作用機序の評価へ反映し、二次無効を最適化候補へ連動
- AZA併用中でも75歳以上、重篤感染症リスク、悪性腫瘍既往があればIFX加点を停止して注意表示
- 「内服アドヒアランス懸念」と「服薬管理に問題がない」を排他的に制御
- 女性でも65歳以上（65～74歳・75歳以上）の場合は「女性のライフステージ」セクション全体を非表示にし、内部では閉経後として処理
- 既使用AT、患者背景・安全性、CD固有情報を独立した入力ブロックへ分離
- CD選択時にVDZ-CDST（ベドリズマブ反応予測）を自動計算
- 腸管手術歴、抗TNFα抗体使用歴、瘻孔型病変歴、アルブミン、CRPから低・中間・高に層別化
- 抗TNFα抗体使用歴は既使用ATから自動判定し、VDZ-CDSTをベドリズマブの推奨根拠へ反映
- 希望する投与経路を、患者背景・既治療・CD固有情報を入力した後の最終項目へ移動
- CDSTのアルブミン入力単位をg/dLに統一し、計算時にg/Lへ自動換算
- CDSTのCRP入力単位をmg/dLに統一し、計算時にmg/Lへ自動換算

## GitHub Desktop / GitHub Pages

1. このフォルダをGitHub Desktopで `Add Existing Repository`（または新規リポジトリ）として追加します。
2. 変更をCommitし、GitHubへPushします。
3. Node.js 22以降で `npm install`、`npm run build` を実行できます。

ルートの `index.html` は外部依存がない完成版です。GitHub Pagesの公開元をリポジトリのルートに設定すれば、ビルドなしで公開できます。`app/` 以下には保守・発展用のReact版も収録しています。

## 開発

```bash
npm install
npm run dev
npm run build
```

## 評価ロジックの注意

採点は候補比較を補助する説明可能なルールベースです。薬剤の適応・禁忌・警告・承認状況は地域や時点で変わるため、必ず最新の添付文書、ガイドライン、患者本人の希望を確認してください。旧版ソースはプロジェクトのFile Libraryおよびローカル `sources/` に存在しなかったため、本版は会話で確定した仕様から再構築しています。
